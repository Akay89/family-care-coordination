# Care Circle Hub

Build a web app called CareCircle. It helps families coordinate the practical admin of caring for a seriously ill or elderly relative in the UK. It is strictly NON-CLINICAL: no medical advice, no symptom tracking, no diagnosis features. Set up the design system first: - Calm, warm, trustworthy feel. Soft neutral background, one muted teal primary colour, one warm accent. Avoid clinical blue/white hospital styling. - Large readable text (base 17px), high contrast, WCAG AA accessible, generous spacing. Many users will be older or stressed. - Mobile-first, responsive layout. - Use plain, kind UK English throughout. Create a public landing page with: - Hero: "Caring for someone is hard enough. The admin shouldn't be." with a short subheading and "Get started free" button. - Three feature sections: Shared family calendar, Task rota, Guided checklists for benefits and paperwork. - A short "Who it's for" section. - Footer with placeholder links: Privacy Policy, Terms, Contact, and a line: "CareCircle does not provide medical advice. In an emergency call 999." Don't build login yet. Just the landing page and a placeholder /app route.
